# LowP - Hyperlocal Real-Time Price Comparator (Amazon, Instamart, Zepto)

A focused, lightweight Chrome Extension (Manifest V3) that compares live grocery & product prices across **Amazon India / Fresh**, **Swiggy Instamart**, and **Zepto** based on your exact location (`Hyderabad 500085` / GPS coordinates).

---

## ⚡ Features

1. **3 Focused Stores**:
   - **Amazon Fresh / India** (Pincode `500085` / Localized)
   - **Swiggy Instamart** (Hyperlocal GPS Dark Store)
   - **Zepto** (10-minute Quick Commerce)
2. **Pure Base Prices**:
   - Compares pure base prices with clear MRP discounts and savings.
3. **Live In-Browser Session Sync**:
   - In-page content script reads from your authentic logged-in session, active Prime/Pass memberships, and saved addresses.
4. **Built-In Debug Inspector**:
   - Click **🛠️ Debug Inspector** in the popup to view real-time request logs, URLs, extracted DOM nodes, and status codes.
   - Click **📋 Copy Debug Log** to copy telemetry with one click.

---

## 🚀 How to Install & Test

1. Open **Google Chrome** and navigate to `chrome://extensions`.
2. Toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked** and select this directory (`c:\Users\Deviant-343\Desktop\LowP`).
4. Click the **LowP extension icon** in your toolbar to compare live prices!
